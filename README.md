# GraphSecure

Counterfactual-Explainable Multi-View Heterogeneous Graph Transformer
for Source Code Vulnerability Detection.

## Project Components

- FastAPI backend
- React frontend
- Joern-based Code Property Graph extraction
- AST, CFG, DFG and PDG graph views
- GraphCodeBERT code embeddings
- Heterogeneous Graph Transformer
- Cross-view attention fusion
- Counterfactual explanations
- Candidate vulnerability patch generation
